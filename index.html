KiriFlow

A personal tool for チョークスラム clip editing. Operated by @SabakiStream.

KiriFlow is not an official TikTok, YouTube, Twitch, or Hololive product. It is an unofficial fan-clip workflow used only by the operator. Clips are prepared for the @ksonChokeslam channel. Nothing is posted automatically. A human chooses every title, cut, and upload.

Viewer accounts are not collected. The software runs on the operator’s machine. Tokens and API keys are not stored in git.
